# Ambient — coming soon

Pre-registration site for the Ambient beta (iPhone & Android). Static HTML on GitHub Pages;
sign-ups go to the `preregistrations` table in Supabase (insert-only via Row Level Security,
see `db/migrations/20260927_preregistrations.sql` in the app repo).

Fonts: Bricolage Grotesque and Geist, SIL Open Font License (see `fonts/`).
